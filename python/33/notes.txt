📖 Interview Definition (Short)

Inheritance is the mechanism by which one class acquires the properties and methods of another class.

👬 Friend's Definition (Very Short)

"Bhai, inheritance ka matlab hai ek class dusri class ke features free me le leti hai, taaki same code dobara na likhna pade."
