Small Integer Optimization (Integer Caching)

Python creates millions of integers.

Creating new objects every time would waste memory.

So CPython pre-creates and reuses small integers in the range:

-5 to 256

Example:

a = 100
b = 100

print(a is b)

Output

True

Memory:

Integer Cache

100
 ▲
 │
a
 │
 ▼
b

Both variables point to the same cached integer object.

Larger Integers
a = 1000
b = 1000

print(a is b)

You may get:

False

String Interning

Python also optimizes many strings by interning them.

Example:

a = "hello"
b = "hello"

print(a is b)

Usually

True
