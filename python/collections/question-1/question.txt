Priority Key-Value Tracker

You are building an in-memory analytics logger that tracks incoming API requests across various endpoints in a microservice framework.

Write a function track_requests that accepts a list of request log tuples and aggregates the 
total count of requests as well as the status code breakdown for each endpoint.

Function Signature
Python
from collections import defaultdict, Counter

def track_requests(log_entries: list[tuple[str, int]]) -> dict[str, dict]:
    pass

Example 1
Input:

Python
log_entries = [
    ("/api/v1/users", 200),
    ("/api/v1/users", 200),
    ("/api/v1/checkout", 500),
    ("/api/v1/users", 404),
    ("/api/v1/checkout", 200),
    ("/api/v1/users", 200)
]
Output:

Python
{
    "/api/v1/users": {

        "total_calls": 2,
        "status_counts": {
            500: 1,
            200: 1
        }
    }
}
